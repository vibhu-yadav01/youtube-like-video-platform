# Streamify — Full Stack Video Sharing Platform

A YouTube-inspired full-stack video-sharing platform designed to provide video streaming, user interaction, subscription management, and real-time communication.

This project is being developed as part of a two-month Full Stack Web Development internship at **ElevanceSkills**.

## Project Overview

Streamify aims to deliver an interactive video-sharing experience with features such as video playback, multilingual commenting, subscription-based access, controlled video downloads, account security, and real-time video communication.

The application is being developed with a modular architecture, focusing on secure API development, database management, frontend integration, and real-time functionality.

## Planned Features

### 1. Multilingual Commenting System
- Nested comments and replies.
- Like and dislike functionality.
- Multilingual comment translation.
- User mentions and comment moderation.
- Spam detection and reporting.

### 2. Subscription Management
- Free, Bronze, Silver, and Gold membership plans.
- Subscription upgrades and downgrades.
- Razorpay test payment integration.
- Payment verification and transaction history.
- Subscription renewal and expiration management.

### 3. Video Download Management
- Subscription-based download limits.
- Download history and tracking.
- Download quota management.
- Duplicate download prevention.
- Secure download authorization.

### 4. Login Security and Personalization
- JWT-based authentication.
- Login history and device tracking.
- New-device OTP verification.
- Trusted device management.
- Personalized theme preferences.

### 5. Custom HTML5 Video Player
- Playback speed controls.
- Fullscreen and picture-in-picture.
- Subtitle support.
- Keyboard shortcuts.
- Watch history and playback progress.
- Autoplay functionality.

### 6. Real-Time Video Calling
- One-to-one and group video calls.
- Camera and microphone controls.
- Screen sharing.
- In-call messaging.
- Participant management.
- Connection and reconnection handling.
